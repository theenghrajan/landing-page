# Landing pages

PPC landing pages, one folder per site named by its domain (e.g. `alliancetel.com/`). `landing-page-master-2026/` is the base template.

## Sessions

- `SESSIONS.md` lists Claude Code session IDs per AC task. Resume with `cd D:\work` then `claude --resume <session-id>` (sessions are stored per launch folder, so launch from `D:\work`).
- When starting work on a new AC task, add a row: date, site, task, topic, session ID, link to the task's `-log.md`.
- Per task keep `MM-DD-YYYY-<taskId>-log.md` and `MM-DD-YYYY-<taskId>-comment.txt` in the site folder. If a session can't be resumed, read those to pick up where it left off.
- Never post comments on AC — draft them in the comment file; the dev posts manually.
